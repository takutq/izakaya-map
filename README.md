# 居酒屋開拓マップ（自分専用デジタル赤ちょうちん PWA）

訪れた・気になっている酒場をピン留めし、「やきとん」「海鮮」「立ち飲み」などのジャンルごとに即座に呼び出せる自分専用のiPhone向けWebアプリ（PWA）。

---

## 1. 起動方法（ローカル開発・自宅Wi-Fi）

```powershell
npm.cmd run dev
```

- **PCから開く**: http://localhost:3000
- **同一Wi-FiのiPhoneから開く**: `http://<PCのIPアドレス>:3000`（例: `http://192.168.11.26:3000`）
  - iPhoneのSafariで開き、「共有」→「**ホーム画面に追加**」をタップするとフルスクリーンアプリとして動作します。

---

## 2. データの保護とバックアップについて

このフォルダのプログラムを編集・アップデートしても、**登録した居酒屋データや行った回数は消えません**。

1. **自動引き継ぎ（LocalStorage永続化）**:
   - 端末内の固定キー（`izakaya_map_records_persistent`）に保存されるため、コードを書き換えてもデータはそのまま残ります。
2. **JSONファイルでの手動バックアップ / 復元**:
   - 画面右上ヘッダーの **「↓（ダウンロード）」ボタン** で、いつでも全店舗データを `.json` ファイルとして保存できます。
   - **「↑（アップロード）」ボタン** から、保存した `.json` ファイルを読み込んで1秒で復元・別端末への移行ができます。
3. **Supabase（クラウドDB）連携**:
   - `.env.local` に `NEXT_PUBLIC_SUPABASE_URL` と `NEXT_PUBLIC_SUPABASE_ANON_KEY` を設定し、`supabase/schema.sql` を実行すると、クラウドデータベース（自分専用RLS保護付き）へ自動切替されます。

---

## 3. バージョン管理（Ver.1 / Ver.2 / Ver.3 の差分保存と復元）

このフォルダは **Git** でバージョン管理されています。フォルダを複製しなくても、以下のコマンド（またはAIへの指示）でいつでも差分保存や過去バージョンへの巻き戻しが可能です。

### 新しいバージョン（例: v2.0）として差分保存するとき
```powershell
git add .
git commit -m "v2.0: 新機能の追加"
git tag -a v2.0 -m "Ver 2.0"
```

### 保存されているバージョン一覧を確認するとき
```powershell
git tag
```

### 過去のバージョン（例: v1.0）の状態を確認・戻すとき
```powershell
git checkout v1.0
```
（元の最新状態に戻る場合は `git checkout master`）
